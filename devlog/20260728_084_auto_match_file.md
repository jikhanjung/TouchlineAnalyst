# 084: headless 가 경기 파일(.match.json) 자동 생성 — GoPro↔AX700 연결

- 날짜: 2026-07-28
- 종류: 기능 (프로젝트 파일 구조 1단계, 사용자 방향)

## 배경

"headless 를 돌리고 나면 어떤 파일이 어떤 파일과 연관되는지 나온다 —
고프로와 AX700 을 연결하는 그걸 프로젝트 파일로 만들어 PitchWatch 에서
불러올 수 있어야 한다" (사용자). 지금까지 .match.json 은 GUI 대화상자로
수동 제작이었다.

## 구현

`--ax700 <dir>` 플래그 → 호각 단계 후 pano 별 `_build_match`:

- pano 와 AX700 각 영상의 호각 이벤트(.whistle.json, 없으면 계산·캐시)
  를 `sync_by_whistles` 대역상관 → 시계 모델 {offset, drift}.
- **품질 게이트(호각 ≥4쌍, rms ≤1s)가 곧 소속 판정** — 옆 구장·다른
  하프 영상은 자동 제외.
- `<pano>.match.json` 저장 (기존 save_match 스키마 v1) → PitchWatch
  "경기 열기 (멀티캠)" 로 즉시 로드. 재실행 안전 (있으면 스킵).
