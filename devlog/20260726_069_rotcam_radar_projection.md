# 069: rotcam 레이더 지면 투영 + 평면 PnP 거울해 방지

- 날짜: 2026-07-26
- 종류: 버그픽스
- 관련: [067](20260726_067_infield_filter.md), [064](20260726_064_rotcam_outlier_robust_calib.md)

## 증상

C0011(rotcam) 레이더에서 선수 전원이 근측 사이드라인에 뭉침 —
"projection 이 안 된 채로 보이는 모양" (사용자).

## 원인 1 — 레이더가 rotcam 을 모름

`_redraw` 레이더 분기가 `_field_calib`(파노라마 캘리브) 없으면
**파노라마 전용 근사**(`ground_positions`: 고정 카메라·수평 기하 가정)
로 폴백. rotcam 은 `_field_calib` 가 항상 None 이라 AX700 에 안 맞는
근사가 적용돼 Y 가 압축 → 사이드라인 뭉침.

**수정**: rotcam 은 프레임별 자세(`_rc_current_pose`)로 발밑을
`pixel_to_field`(광선-지면 z=0 교차) 투영해 경기장 절대 좌표 레이더.
공도 동일 투영. 자세 계산은 장외 필터와 공용(rc_pose 한 번). 자세를
못 푼 프레임은 **빈 레이더** (엉뚱한 근사보다 안전). 파노라마 폴백은
비-rotcam 전용으로 격리.

## 원인 2 — 평면 PnP 지면 반사 거울해 (검증 중 발견)

필드 점이 전부 z=0 이라 **카메라를 지면에 반사한 해(z<0)도 재투영이
거의 같다** — 특히 AX700 같은 망원(약한 원근)에서 두 해의 rms 차이가
미미해 `solvePnP` 가 거울해를 뽑을 수 있다. 거울해면
`pixel_to_field` 의 지면 방향 게이트에 걸려 **전부 NaN** → 레이더
빈 화면 + (기존 장외 필터에선) 전원 숨김 사고 가능.

**수정**:
- `_fscan_pnp`: `solvePnPGeneric`(IPPE 양해 반환)으로 두 해를 다 받아
  **물리해(cam z>0) 우선** 선택 ((지면아래?, rms) 사전식).
- 장외 필터: 투영이 전원 NaN 이면 필터 자체를 생략 (전원 숨김 방지).

## 검증

- 망원(f=3200)+1px 노이즈 합성: 캘리브 z=+8.02(물리해), f 정확,
  지면 투영 8/8 유한·오차 max 0.15m·피치 전역 [-40,40]×[-25,25] 퍼짐.
- rotcam 테스트 9개 통과.
