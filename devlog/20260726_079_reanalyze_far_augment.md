- 날짜: 2026-07-26
- 종류: 기능 (P04 재분석 배치 준비)
- 관련: [077](20260726_077_far_person_detection.md), [078](20260726_078_far_tracklets_tracker_tuning.md)

## 배경 (사용자 질문)

"재분석은 기존 결과에 추가하는 거냐, 새로 하는 거냐" — 개선별로 답이
다르다:
- 원경 타일 사람 검출 → **추가 가능** (별도 패스)
- 이중 conf + 트래커 튜닝 → **전체 재분석 필요** — 트래커를 다시
  돌리므로 **tid 전부 교체 → .ptz.json 수동 편집(역할·병합·번호,
  tid 로 연결)이 고아화**. 편집 많은 영상(pano_5316: 번호 86개)엔 손해.

## 구현 (headless 플래그 2개)

- `--reanalyze`: 분석을 처음부터 (신 검출 전체 반영). help 에 편집
  고아화 경고 명시. 편집 없는 영상용.
- `--far-augment`: `augment_far_persons` — 기존 분석에 원경 타일
  사람만 추가. 메인 패스 재실행 없음(비용 = 순차 디코드 + 타일 추론),
  기존 tid·편집 보존, far tid 800001+ (_FarTracker). 재실행 안전
  (far_augment 메타로 이미 보강 시 스킵). 편집한 영상용.
- 타일 검출을 `_far_person_tiles` 헬퍼로 공용화 (analyze_video 와
  augment 가 단일 경로).
