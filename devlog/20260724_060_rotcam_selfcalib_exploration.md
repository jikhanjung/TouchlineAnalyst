# 060: 회전/줌 모델 제대로 세우기 — 자가캘리브 탐색 결과

- 날짜: 2026-07-24
- 종류: 탐색/알고리즘 설계
- 관련: [059](20260724_059_rotcam_realdata_findings.md) (단일기준 실패),
  [P06](20260720_P06_multicam_fusion_plan.md) 3단계

## 질문

랜드마크는 놔두고, 팬+약간 줌 영상에서 호모그래피만으로 회전/줌
모델을 세우는 방법. (C0011 실데이터로 탐색)

## 발견 1 — 순수 팬은 초점거리 자가캘리브에 퇴화

C0011 팬 구간(200s) 연속 호모그래피 37개로 f 를 1D 탐색(각 스텝
decompose_H 정규직교 잔차 합 최소):

```
f/W  0.5   1.0   1.5   2.0   2.4
잔차 0.67  0.27  0.13  0.05  0.01   ← 단조 감소, 수렴 안 함
```

잔차가 f 를 키울수록 계속 줄어 발산 (f/W 2.4+). **수평 팬(한 축
회전)은 f 를 결정 못 한다** — Sturm 임계 운동. AX700 이 팬 위주라
호모그래피만으론 f 불능. (059 의 랜드마크 PnP f 폭주도 같은 원인.)

## 발견 2 — 조밀 궤적은 회전을 안정적으로 준다

2초 간격 그리드(818프레임)의 인접 호모그래피: **816/817 링크 성공**.
1~2초 간격이면 겹침이 커 매칭이 거의 항상 된다 (고정 삼각대). 즉
**상대 회전 궤적 R(t)·줌비는 조밀 샘플링으로 견고**.

## 발견 3 — f 는 다프레임 랜드마크 번들로

f 는 랜드마크가 필요하되, 여러 프레임 랜드마크를 궤적 회전으로
**한 추정에 모으면** 퇴화가 풀린다 (깊이 다양성 확보). 번들 미지수:
cam_pos(3)+f(1)+절대회전 R0(3)=7, 상대회전은 궤적서 고정.

**막힌 지점**: 누적 호모그래피가 끊긴 링크 1개 이후 전부 None 전파 →
번들이 3/14 랜드마크만 써 과적합(rms 0, cam 100m 밖). 끊긴 링크
복구(건너뛰기/직접 브리지)가 마지막 관문.

## 확정된 아키텍처 (사용자 방향과 일치)

1. **조밀 호모그래피 궤적** (오프라인 SIFT, 1~2s) → 상대 R(t)·줌.
   끊긴 링크는 건너뛰기(gap+2 직접 매칭)로 복구, 누적은 앵커 리셋.
2. **랜드마크(여러 프레임 OK) + 궤적 → 번들** 로 절대 f·설치·R0 고정.
3. **.rotcam.json 사이드카**: 프레임별(or 1s) rvec + f 기록.
4. GUI/융합은 사이드카만 읽어 임의 프레임 자세·A→B 회전 즉시.
