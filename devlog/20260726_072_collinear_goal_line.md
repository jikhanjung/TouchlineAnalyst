# 072: 골라인 공선 구속 — 랜드마크 라인 멤버십으로 골라인 추정

- 날짜: 2026-07-26
- 종류: 기능 (정확도)
- 관련: [071](20260726_071_goalpost_landmarks.md), [070](20260726_070_live_landmark_refit.md)

## 배경 (사용자 방향)

C0011 에서 가까운 왼쪽 코너가 화면 밖 → 근사 클릭(화면 가장자리)하면
왼쪽 골라인이 실제보다 바깥으로 그려지고 페널티박스 정렬도 틀어짐.
사용자: "왼쪽 골라인에 위치한 여러 점이 있으니 그걸로 골라인을
추정하게 하면 어때?"

핵심 통찰: 골라인 위 랜드마크(코너·골포스트·페널티박스 교차)는 선상
위치가 부정확해도 **라인 위에 있다는 사실**은 정확하다 — 점 대응이
기각(RANSAC)되거나 강등(IRLS)돼도 라인 거리 구속은 살릴 수 있다.

## 구현

- `LM_LINE_FAM`: 랜드마크 → `_marking_lines` 패밀리 매핑 (왼쪽 골라인
  =2 에 코너 2·골포스트 2·페널티 교차 2, 오른쪽=3 동일).
- **전역 캘리브** (`_refit_field_rotcam`): 찍힌 공선 랜드마크의 기준
  프레임 픽셀을 point-to-line 구속으로 자동 추가 (수동 라인 점과 합류).
- **프레임별 자세** (`_rc_current_pose`) — 그리는 라인의 주체:
  Kabsch(IRLS) 후 `_refine_pose_p2l` 로 (R, f) 정밀화 — 공선 랜드마크
  + 수동 라인 점(현재 프레임 이송, H 캐시)을 라인 거리로 반영.
- **정책 변경**: `calibrate_reference_lines` 의 구 폴백 정책(점 6개
  이상이면 라인 무시)을 폐기 — 라인 점이 있으면 항상 반영 (cam 고정
  + f σ3% 앵커 + Huber 라 점 해를 크게 흔들지 않음).

## 검증

실패 시나리오 합성 (전역 f 4% 오차, 프레임에 FL 정확 + NL 선상 8m
어긋난 가장자리 클릭 + 중앙 1점, 3px 노이즈):
- Kabsch 만: 골라인 **수직 편차 20.3px** (IRLS 가 NL 을 강등해 라인이
  한 점 구속으로 표류)
- +공선 라인구속: **0.9px — 23.7배 개선** (라인이 클릭 픽셀들을 통과)

주의: 평가지표는 수직 편차 — 대응점 거리로 재면 f 오차의 선상
미끄러짐까지 세서 개선이 가려진다(res_w=0 인데 편차 커 보이는 함정).
전역 캘리브는 RANSAC 이 어긋난 점을 기각해 원래도 견고, 라인 구속은
무해(편차 동등~소폭 개선). 테스트 146개 통과.
