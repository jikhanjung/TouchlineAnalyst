## 재생 성능
- **헤드리스 스크럽 프록시** (.scrub.mp4, 1600px): 스티칭 직후 자동
  생성, 재생이 원본 5900px 대신 프록시 디코드. 완료 경기 7개는
  소급 생성 (CPU libx264, NVENC 배치와 경합 회피).
- **재생 중 다운스케일**: 프록시 없어도 표시 폭 1600 으로 줄이고
  오버레이 좌표 맞춤, 정지 시 원해상도 복원.

## 대기 커서
- 영상 열기 전체 흐름(open_path/open_match, match.json 로드)과
  **레인 계산(_link_done)** 을 대기 커서로 감쌈 — 정작 느린 트랙
  연결 후 계산에 커서가 없던 문제.

## 트랙릿 상호작용
- 클릭 시 **클릭 지점 최근접 검출**로 이동 (희소 트랙릿이 시작으로
  튀어 아무도 안 잡히던 문제 — 실사례 38:13).
- 선택 = **빨간 테두리** (영상 박스 + 타임라인 바 양쪽).
- 호버 툴팁: tid(+병합 대표+번호). 정적 툴팁 중복 제거.
- **병합 그룹 밴드**: 같은 rep 멤버는 한 행 + 그룹 전체 반투명 밴드
  (사이 갭 = 놓친 시간 시각화).

  방어적 인덱스 가드.
