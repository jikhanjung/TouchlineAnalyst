# 077: 원경 선수 검출 개선 — 문턱이 아니라 해상도가 병목

- 날짜: 2026-07-26
- 종류: 기능 (검출 품질)

## 배경 (사용자 제안)

"검출 threshold 를 낮추는 게 좋을 것 같다 — 파노라마에서 원경 선수가
거의 안 잡히는데 수동 재검출은 잡힌다."

## 진단 — 실프레임 A/B/C (pano_5316)

| 방법 | 20분 | 40분 |
|---|---|---|
| A) 절반해상도(3264px) conf 0.2 (기존) | 5명 | 7명 |
| B) 절반해상도 conf 0.1 (문턱만 낮춤) | **5명** | — |
| C) 원경 네이티브 타일 conf 0.1 | **7명** | **16명** |

**문턱만 낮추면 이득이 0** — 원경 선수(수십 px)는 절반 해상도에서
conf 이전에 픽셀이 부족하다. 수동 재검출이 잡는 이유 = 네이티브 해상도.
far_boost 타일(네이티브)이 이미 있었지만 **공 전용**(classes=[BALL])
이었다.

## 구현 (`analyze_video`)

1. **원경 타일에 사람 클래스 추가** — 기존 공 타일과 같은 추론이라
   추가 비용 ~3% (실측 메인 6.9s vs 타일 0.2s). conf_far(0.1) 이상만,
   기존 박스와 근접 중복 제거, conf 순 삽입(타일 겹침 자체 정리).
   tid=-1 (추적기 밖 검출 — 트랙릿은 안 생기고 박스/레이더 표시).
2. **사람 이중 문턱**: track 을 min(conf) 로 돌리고 근측은
   conf_near(0.2, FP 억제)·원경 밴드는 conf_far(0.1, 회수 우선) —
   장외 자동 필터(067)가 FP 를 기하로 걸러 낮은 문턱의 부담이 줄었다.
3. 파라미터 conf_near/conf_far 노출, 체크포인트 키·분석 메타에 기록
   (구 체크포인트 자동 무효).

## 적용 조건 / 한계

- 분석은 캐시(.analysis.json)라 **재분석해야 반영** (영상당 수 시간).
- 타일 사람(tid=-1)은 추적이 안 붙는다 — 팀 분류·트랙릿 병합 대상이
  아니고 표시·레이더용. 원경 추적까지 원하면 후속(타일 좌표로 2차
  트래커 등).
