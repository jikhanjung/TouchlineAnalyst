# 067: 장외 자동 숨김 — 경기장 안 사람만 인식

- 날짜: 2026-07-26
- 종류: 기능
- 관련: [066](20260726_066_ax700_jersey_ocr.md) (AX700 OCR),
  [064](20260726_064_rotcam_outlier_robust_calib.md)

## 배경

사용자 방향: "경기장 캘리브레이션이 되면 그 후에는 경기장 안에 있는
사람만 인식하면 된다." 기존에는 검출 단계의 `field_top_frac`(수평 컷 —
원경 트랙·관중석)만 있고, 캘리브 기반 피치 사각형 게이트는 없었다.

## 구현 (비파괴 — hidden_players 와 같은 층)

**파노라마 — 트랙릿 일괄 판정** (`_update_outfield`):
- 전 샘플의 발밑점(cx, cy+h/2)을 `pano_to_field` 로 일괄 투영(표본 상한
  ~4천 샘플, 발밑 캐시는 analysis 당 1회).
- 트랙릿(병합 대표)별로 **과반이 피치+여유(2m) 밖**(수평선 위 NaN 포함)
  이면 장외 → `_outfield` 집합. 경계 선수(스로인 등)는 과반 규칙+여유로
  생존.
- 트리거: 캘리브 변경(`_refit_field`)·트랙 연결 완료(`_link_done`)·토글.

**rotcam — 현재 프레임 판정** (_redraw): 팬 카메라는 프레임별 자세가
필요해 일괄 판정 불가 — 표시 시점에 `_rc_current_pose` 로 발밑을
`pixel_to_field`(z=0 교차) 투영해 피치 밖을 거른다. 자세를 못 푼
프레임은 필터 없이 전부 표시(엉뚱하게 숨기느니 안전).

**적용 지점**: `_person_excluded()`(수동 숨김 ∪ 자동 장외)로 통일 —
표시 박스, 선수 목록, 레이더, 크롭 계획(exclude_tids), OCR 후보(장외
트랙릿 역할 -1 위장). 분석 원본은 그대로.

**UI**: 오버레이 토글 행에 "장외 숨김" 체크박스 (기본 켬, QSettings
지속). 링크 완료 시 "장외 트랙릿 N개 자동 숨김" 로그.

## 검증

- pano_5316 실데이터: 트랙릿 1702개 중 **장외 609개** 판정(0.27s) —
  육상 트랙 통행인·관중 트랙릿 대량 정리. 검출 기준 ~10%가 피치 밖.
- 전체 테스트 146개 통과.

## 참고

- rotcam 필터는 `_rc_current_pose` 재사용 — 랜드마크 있는 rotcam 은
  스크럽마다 이미 이송(SIFT, _rc_H 캐시)을 하므로 추가 비용 미미.
- `_player_at`(클릭 히트)은 `_players_row` 경유라 파노라마 장외는 클릭도
  안 잡힘. rotcam 프레임 필터는 표시 전용이라 히트는 그대로(사소).
