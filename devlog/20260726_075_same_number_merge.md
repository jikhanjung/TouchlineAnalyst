# 075: 같은 등번호 트랙릿 일괄 병합

- 날짜: 2026-07-26
- 종류: 기능 (사용자 방향)

## 배경

번호 지정 시점의 자동 병합(`_set_player_num`, 동시 등장 없으면 병합)이
생기기 **전**에 만든 데이터는 같은 등번호가 여러 트랙릿에 흩어져 있다.
pano_5316 실측: 중복 번호 그룹 15개, 한 번호에 최대 16개 트랙릿.

## 구현

분석 메뉴 "같은 등번호 트랙릿 병합" (`merge_same_numbers`, PitchWatch
+ PitchStitch):

- 대표별 **등장 샘플 집합**을 1패스로 구축 (extra 포함) → 동시 등장
  판정이 집합 교집합으로 즉시.
- (팀, 번호)별 그룹 — 팀은 `_role_of`(자동 분류 폴백)로 해석.
- 후보를 **이미 수락된 그룹 전원**과 비교해, 동시 등장 >2샘플이면
  물리적으로 다른 사람(오배정)으로 보류 + 로그. 아니면 병합.
- 병합은 `merge_map`(union) 재구축 — 기존 수동 병합과 합류, 대표는
  검출 최다.

## pano_5316 드라이런

(같은 화면에 15번이 두 명 등 — 한쪽 번호가 오배정, 수동 검토 대상).
