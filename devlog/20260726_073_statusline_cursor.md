# 073: 하단 상태줄 + 영상 커서 화살표

- 날짜: 2026-07-26
- 종류: UX (사용자 방향 2건)

## 하단 상태줄

PtzTab 맨 아래(진행바 밑)에 한 줄 상태줄 — **마지막 로그 메시지**를
보여줘 로그 탭을 안 열어도 지금 뭘 하는 중인지 보인다. `log()` 가
타임스탬프 포함 그대로 흘리되, 스크럽마다 반복되는 상세 로그
(`_STATUS_SKIP`: "원본 승격"/"폐기")는 상태줄에서만 제외 (로그 탭엔
전부 남음). `_busy` 시작/완료·워커 단계 로그가 모두 `log()` 경유라
상태줄에 자동 반영. 긴 메시지가 창 폭을 늘리지 않게 SizePolicy Ignored.

FramePane 이 평상시 손바닥(OpenHand) 커서였던 걸 일반 화살표로 —
