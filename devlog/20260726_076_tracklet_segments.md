## "화면에 없는데 흰 막대" 의 정체 (사용자 질문에 대한 답)

"병합이 빈 부분을 채운 것 아니냐" — **아니다**. 병합 밴드는 반투명이
맞고, 범인은 **단일 트랙릿의 내부 공백**: 트래커가 오래 사라진 사람에게
같은 ID 를 재부착하면 한 트랙릿 안에 수십 초 공백이 생기는데,
타임라인은 트랙릿을 스팬 통짜 막대(f0→f1)로 그려 공백 구간에도 흰
막대가 보였다. 실측(pano_5316): 15번 #3815 는 211s 스팬에 **63.7s
공백**(40:55~41:58), 전체 2047개 중 **335개**가 내부 공백(>2s) 보유.

**수정**: `analysis_summary` 가 트랙릿별 **검출 세그먼트**(공백>2s
분절)를 산출(.analysis.cache.json 에 캐시, 구 캐시는 자동 무효) →
타임라인 막대를 세그먼트 단위로 그림. 공백은 반투명 그룹 밴드로만
표시 (내부 공백 있는 단독 트랙릿도 밴드). #3815 → 3세그먼트 분리 확인.

## 추적 확장 결과의 트랙릿 반영

`_player_cache` 가 수동 검출(extra) 스팬을 **행마다 덮어써** ±4s 확장
결과가 마지막 1프레임으로 붕괴하던 버그 — 프레임을 모아 min/max/개수
+ 세그먼트로 집계. 이제 확장하면 타임라인 트랙릿이 그만큼 길어져
보인다 (사용자 방향).
