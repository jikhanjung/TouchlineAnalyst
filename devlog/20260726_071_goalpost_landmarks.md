# 071: 골포스트 랜드마크 + 찍기 동선 순서 재배열

- 날짜: 2026-07-26
- 종류: 기능
- 관련: [070](20260726_070_live_landmark_refit.md)

## 골포스트 밑동 4점 (사용자 방향)

`goal_l_far/near`, `goal_r_far/near` — 각 골대 포스트 밑동 (골라인 위
z=0, ±GOAL_HALF_W=3.66m). 태그 GLF/GLN/GRF/GRN.

핵심 가치: **골포스트·코너·골라인×페널티박스 점이 전부 같은 골라인 위
(공선)** — 가까운 코너가 화면 밖이거나 가려져도 골포스트 2점이
엔드라인 방향을 강하게 구속한다 (C0011 엔드라인 어긋남의 처방).
포스트는 흰 기둥이라 화면에서 찾기도 쉽다.

참고: 유소년 구장 등 골대가 7.32m 가 아니면 오차 유입 — 필요해지면
circle_r 처럼 venue 파라미터화.

## 찍기 동선 순서 (사용자 방향)

컨텍스트 메뉴·경기장 탭 목록·찍기 모드 제안이 따르는 LANDMARKS 순서를
왼쪽→오른쪽 스윕으로 재배열:

왼쪽 코너(2) → 왼쪽 골대(2) → 왼쪽 페널티박스(4: 골라인 교차 2 + 박스
모서리 2) → 중앙선(4: HF·CF·CN·HN) → 오른쪽은 반대 순서(박스 → 골라인
교차 → 골대 → 코너) → 보조(센터서클 좌우, 선 위 점들).

순서는 UI 표시 전용 (사이드카는 키로 저장) — 기존 데이터 영향 없음.

## 검증

전 랜드마크 위치·태그 누락 없음, 왼쪽 골라인 6점 X 동일(-47.5) 공선
확인, 테스트 146개 통과.
